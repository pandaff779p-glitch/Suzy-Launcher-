# Suzy Launcher — Pink Edition

O **Suzy Launcher** recebeu uma nova identidade visual inspirada em tons de rosa neon e preto, com uma nova logo personalizada e melhorias na interface.

## Novidades

- Nova logo rosa neon aplicada ao aplicativo.
- Ícones atualizados para todas as densidades do Android.
- Tema completo em rosa, substituindo os antigos tons roxos.
- Fundo preto mantido para combinar com a nova identidade visual.
- Interface principal e tela de configurações traduzidas para português brasileiro.
- Remoção de laga e lentidao.
- Remoção da tela de loading que poderia deixar o aplicativo preso em uma tela preta.
- Ajustes de estabilidade e otimização da interface.
- Links públicos atualizados para o repositório oficial do projeto.

## Instalação

1. Baixe o APK disponível na seção **Releases**.
2. Ative a instalação de aplicativos de fontes desconhecidas no Android, caso necessário.
3. Instale o APK.
4. Abra o Suzy Launcher e configure suas preferências.

> Antes de instalar, recomendamos fazer backup das suas configurações, contas, mundos e instâncias existentes.

## Identidade visual

A nova versão utiliza:

- Rosa neon como cor principal.
- Rosa claro para destaques e botões.
- Rosa escuro para contrastes.
- Preto profundo como cor de fundo.
- Nova logo personalizada com estética rosa neon.

## Aviso

Este projeto é uma versão modificada e independente de um launcher para Minecraft Java Edition no Android. Ele não é afiliado oficialmente à Mojang Studios, Microsoft ou às equipes dos projetos originais utilizados como base.

Use por sua própria conta e risco e faça backups antes de atualizar.
