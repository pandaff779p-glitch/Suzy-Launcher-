# Suzy-Launcher-
💜 Suzy Launcher

«Um launcher para Minecraft: Java Edition em dispositivos Android.»

O Suzy Launcher é um projeto com identidade visual em preto e roxo, pensado para organizar o projeto, a documentação e as futuras versões para Android.

📱 Sobre o projeto

- Nome: Suzy Launcher
- Plataforma: Android
- Jogo: Minecraft: Java Edition
- Tema: Preto e roxo
- Estado: Em desenvolvimento

As funcionalidades e a compatibilidade serão documentadas à medida que o projeto evoluir.

📥 Download

Quando uma versão estiver pronta, os ficheiros de instalação serão disponibilizados na página de versões.

"📦 Ver downloads e versões" (../../releases)

Ainda não existe um APK confirmado neste repositório.

🛠️ Desenvolvimento

O código-fonte, os requisitos e as instruções de instalação serão adicionados quando estiverem disponíveis.

🐛 Reportar erros

Encontraste algum problema? Abre uma "Issue" (../../issues) e explica o que aconteceu, incluindo a versão do Android, se aplicável.

Não publiques palavras-passe, tokens ou outros dados privados.

⚠️ Aviso

Suzy Launcher é um projeto independente, sem afiliação oficial à Mojang Studios ou à Microsoft. Minecraft é uma marca dos respetivos titulares.
