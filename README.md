## Sobre o projeto

O **Suzy Launcher** é uma versão personalizada de um launcher para Minecraft Java Edition no Android. O projeto foi desenvolvido com foco em uma experiência visual marcante, simples de configurar e adaptada para quem prefere uma interface escura com detalhes em rosa neon.

A nova edição traz uma identidade visual própria, uma logo personalizada e melhorias na organização da interface. O objetivo é oferecer uma base prática para iniciar o Minecraft Java Edition em dispositivos Android, mantendo opções para contas, instâncias, mods, renderizadores, controles e gerenciamento de memória.

> Este projeto é independente e não possui afiliação oficial com Mojang Studios, Microsoft ou com as equipes dos projetos originais utilizados como base.

## Destaques da versão atual

- Logo personalizada em rosa neon.

- Configurações traduzidas para português brasileiro.

- Links de doação removidos da interface e dos callbacks internos.

- Recursos visuais mantidos em tamanhos adequados para diferentes densidades do Android.

## Instalação

1. Acesse a página de [Releases](https://github.com/pandaff779p-glitch/Suzy-Launcher-/releases).
2. Baixe o APK mais recente.
3. Caso o Android solicite, permita a instalação de aplicativos desta fonte.
4. Instale o APK no dispositivo.
5. Abra o Suzy Launcher e configure a conta, a instância e a memória disponíveis.

Antes de atualizar, faça backup das suas configurações, contas, instâncias, mods, mundos e arquivos importantes. Como o identificador do pacote foi alterado, o Android pode tratar esta versão como um aplicativo diferente da instalação anterior.

## Configuração recomendada

Para obter uma experiência mais estável:

- Reserve memória suficiente para o Minecraft sem comprometer o sistema Android.
- Use versões e modpacks compatíveis com o hardware do dispositivo.
- Ative renderizadores adequados para a GPU do celular.
- Evite utilizar mais mods do que o aparelho consegue carregar.
- Mantenha espaço livre no armazenamento para bibliotecas, assets, mundos e arquivos temporários.
- Faça backup antes de alterar renderizadores ou configurações avançadas da JVM.

A quantidade ideal de memória depende do aparelho, da versão do Minecraft, da resolução e do modpack utilizado. Mais memória nem sempre significa mais desempenho.

## Compatibilidade

O aplicativo foi preparado para dispositivos Android modernos compatíveis com as dependências do launcher. O desempenho pode variar de acordo com:

- Modelo e arquitetura do processador.
- GPU e driver gráfico disponível.
- Quantidade de RAM.
- Versão do Android.
- Versão do Minecraft Java Edition.
- Quantidade de mods e recursos ativos.
- Renderizador selecionado.

Dispositivos diferentes podem apresentar resultados diferentes. Em caso de falha, teste primeiro uma instância limpa, sem mods, com uma configuração de memória moderada.

## Estrutura de recursos

O launcher possui áreas para:

- Gerenciamento de contas.
- Criação e seleção de instâncias.
- Instalação e gerenciamento de mods.
- Configuração de controles virtuais.
- Seleção de renderizador gráfico.
- Ajuste de memória RAM e argumentos da JVM.
- Personalização do plano de fundo.
- Configurações de gravação de tela.
- Gerenciamento de skins e capas quando suportado pelo serviço utilizado.

## Solução de problemas

### O aplicativo não abre

Desinstale somente se necessário e reinstale o APK. Antes disso, preserve os arquivos importantes do launcher. Também vale testar o aplicativo após reiniciar o dispositivo e liberar espaço de armazenamento.

### O Minecraft fecha durante a inicialização

Teste sem mods, reduza a memória alocada, altere o renderizador e confirme se a versão escolhida é compatível com a instância. Mods incompatíveis ou bibliotecas incompletas podem causar encerramentos durante o carregamento.

### O desempenho está baixo

Reduza a distância de renderização, diminua a escala de resolução, escolha um renderizador compatível com a GPU e evite deixar vários aplicativos pesados em segundo plano.

### A instalação não substitui a versão anterior

A versão atual utiliza o pacote `com.pandaff.suzylauncher`. Por isso, ela pode ser instalada como um aplicativo separado. Faça backup dos dados antes de remover qualquer versão anterior.
